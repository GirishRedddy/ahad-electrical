AHAD ELECTRICAL - NETLIFY BUILD
Deploy by dragging this folder or the ZIP into Netlify.
Included: responsive homepage, six Ahad service pages, mega-menu, service finder, reviews center shell, projects shell, service-area search shell, FAQ, contact form, multi-step estimate form, Netlify form attributes, mobile navigation, sticky mobile CTA, animations, sitemap, robots, security headers.
Important final integrations:
1) Reviews: connect only the verified Ahad Google Business Profile / Yelp listing. No ratings or reviews were invented.
2) Chat: connect the existing GoDaddy Website Chat at final deployment if GoDaddy provides an external embed. If it is GoDaddy-platform-only, use an external chat provider or equivalent on Netlify.
3) Project gallery: replace the gallery shell with Ahad's actual project images.
4) Service areas: populate only verified Ahad service cities/ZIPs.
The logo uses the user's supplied Ahad logo, carefully upscaled/sharpened rather than replaced with an invented logo.

BOOKING: Service cards now open a five-step booking request flow with calendar, preferred time, address, contact and review. Times are intentionally labeled preferred until a live availability backend/calendar is connected, preventing false real-time availability claims.
